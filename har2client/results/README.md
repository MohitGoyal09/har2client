## How the 30 Tier A tasks were chosen (`runs/set30`)
From `data/selected_specs.jsonl` (165 APIs):
1. **Pilot 12:** shuffle all 165 with `random.Random(7)`, take the first 12.
2. **18 more, balanced by auth type:** remove the 12; shuffle the rest with `random.Random(30)`; walk the list and keep an API while its auth type is below the target count (none 7, apiKey 8, bearer 8, basic 7 in total, counting the pilot).
3. **Replacements:** 2 of the 18 failed to build (`listennotes.com`: OpenAPI 3.1; `whapi.com:bets`: 2 usable ops), both auth `none`. Replacements of type `none` were drawn from the remaining APIs shuffled with `random.Random(31)`, building in order until 2 succeeded. Skipped on the way: `seldon.local:core` (0 usable ops), `ote-godaddy.com:subscriptions` (4), `seldon.local:wrapper` (0), `apple.com:sirikit-cloud-media` (3). Built: `ote-godaddy.com:certificates`, `telematicssdk.com`.
Final: 30 tasks; auth: bearer 8, apiKey 8, basic 7, none 7. Build: `--noise 0.7 --seed 1`.
